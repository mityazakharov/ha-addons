# sing-box proxy

Дополнение Home Assistant: SOCKS5/HTTP-прокси на [sing-box](https://sing-box.sagernet.org) для интеграций, которым нужен обход блокировок (например, Telegram bot).

Прокси доступен только внутри HA, в локальную сеть порт не открыт. Адрес — имя хоста дополнения и порт 1080: `<хеш репозитория>-sing-box-proxy:1080`. Имя хоста показано на вкладке «Информация» дополнения.

## Установка

1. Подключить репозиторий: «Настройки» → «Дополнения» → «Магазин дополнений» → ⋮ → «Репозитории» → `https://github.com/mityazakharov/ha-addons`.
2. Открыть sing-box proxy → «Установить».
3. На вкладке «Конфигурация» вставить ссылки, сохранить.
4. На вкладке «Информация» включить «Сторожевой таймер» (Watchdog) и «Запуск при загрузке», запустить.

Для установки без GitHub папку `sing_box_proxy` можно скопировать в общую папку `addons` (Samba). Тогда дополнение появится в разделе «Local add-ons», а имя хоста будет `local-sing-box-proxy`.

## Настройки

| Параметр | Описание |
|----------|----------|
| `primary_link` | Основная ссылка `vless://` или `ss://` |
| `backup_link` | Резервная ссылка, необязательно |
| `test_url` | Адрес, доступность которого проверяется раз в минуту через каждую ссылку |
| `log_level` | Уровень логов sing-box |

Поддерживается:
- VLESS: Reality, TLS, без шифрования; транспорт tcp, ws, grpc, httpupgrade, http (h2). Транспорт xhttp sing-box не поддерживает.
- Shadowsocks: SIP002 (`ss://base64(метод:пароль)@сервер:порт`), Shadowsocks-2022 (`ss://метод:ключ@сервер:порт`), старый формат `ss://base64(...)`. Плагины не поддерживаются.

## Две ссылки

Если задана резервная ссылка, sing-box раз в минуту проверяет `test_url` через обе и направляет трафик через рабочую, с меньшей задержкой. Чтобы не переключаться туда-сюда из-за мелких колебаний, текущая ссылка меняется, только если другая быстрее больше чем на 300 мс или текущая перестала отвечать.

## Подключение в интеграции

Telegram bot: «Настройки» → «Устройства и службы» → Telegram bot → ⋮ → «Перенастроить» → Proxy URL: `socks5://<имя хоста дополнения>:1080`.
