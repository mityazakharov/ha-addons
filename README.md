# ha-addons

Репозиторий дополнений Home Assistant.

| Дополнение | Описание |
|------------|----------|
| [sing-box proxy](sing_box_proxy/) | SOCKS5/HTTP-прокси для интеграций HA через VLESS или Shadowsocks |

## Подключение репозитория

«Настройки» → «Дополнения» → «Магазин дополнений» → ⋮ → «Репозитории» → вставить `https://github.com/mityazakharov/ha-addons` → «Добавить».
